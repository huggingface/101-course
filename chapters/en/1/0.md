# Hello, Hub! Your First Steps with AI

Welcome to Unit 1! 

Now that you've completed the onboarding in Unit 0, it's time to get hands-on with AI models and start building your presence on the Hugging Face Hub.

In this unit, you'll learn three progressively more powerful ways to work with AI models: browser-based AI, inference with Python, and sharing your work with the community in repositories.

## What You'll Learn

You'll start with browser-based AI where no coding is required. This means using model widgets to try text generation, image creation, and more. You'll also explore the Inference Playground for advanced model experimentation and learn to compare different models side-by-side.

Next, you'll move into programming with Python by learning to use the `InferenceClient` or OpenAI API client to integrate AI into your applications. You'll build interactive AI applications with just a few lines of code, using the environment setup you completed in Unit 0.

Finally, you'll learn to share your work with the community by creating your first repository on the Hugging Face Hub. This includes writing effective model cards and documentation, uploading files using both web interface and Python SDK, and building interactive Spaces to showcase your AI projects.

> [!TIP]
> New to AI? Don't worry! This unit assumes no prior experience. We'll explain everything as we go and provide plenty of examples.
>
> Already Experienced? Feel free to skim the basics and focus on the hands-on exercises and advanced examples.

## Ready to Get Started?

By the end of this unit, you'll have hands-on experience with multiple AI models for text, images, and audio. You'll have written your first AI-powered Python applications and created repositories on the Hugging Face Hub. 

Let's dive in and start exploring the exciting world of open-source AI!
