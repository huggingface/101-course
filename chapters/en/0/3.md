### What libraries are we using?

Before we start installing the libraries, let's briefly review what each library does, and why we are using them.

The [`huggingface_hub`](https://huggingface.co/docs/huggingface_hub/en/index) library serves as your primary connection to the Hugging Face Hub, handling authentication, model downloads, and uploads. It manages the communication between your local environment and the vast repository of AI models and datasets.

The [`transformers`](https://huggingface.co/docs/transformers/en/index) library provides access to thousands of pre-trained models spanning text, images, audio, and multimodal tasks. It offers a unified API for loading, using, and fine-tuning state-of-the-art models like BERT, GPT, and DeepSeek R1, making it easy to switch between different architectures for your specific needs. `transformers` is used by everyone from scientists to hackers, and in this course we will just scratch the surface of what it can do.

The [`datasets`](https://huggingface.co/docs/datasets/en/index) library simplifies working with machine learning datasets. It provides efficient loading and processing of popular datasets, along with tools for preparing your own data. The library handles memory management automatically, making it possible to work with datasets that are too large to fit in memory.

Finally, [`gradio`](https://www.gradio.app/docs) enables you to build interactive web demos with minimal code. You can create user-friendly interfaces for your AI models, allowing others to test and interact with your work directly through a web browser.

Google Colab is the easiest way to get started - no installation required! Just open a notebook in your browser and start coding. It is not so ideal for long-term projects or building web applications, so when we get to the project sections of the course, we will be using other options below.

Install the Hugging Face libraries with pip. In Colab, use `!` before pip commands:

```python

!pip install huggingface_hub transformers datasets gradio

!pip install -U "huggingface_hub[mcp]"
```

> [!TIP]
> During the course, if you need to install a specific library, like `"huggingface_hub[mcp]"` shown above, we'll let you know.

Test that everything installed correctly:


## Local Python Setup

Let's move on to setting up a local Python environment with the `uv` package manager.

> [!TIP]
> `uv` is a great tool for managing Python projects. We recommend it for all your projects. Check out the [uv documentation](https://docs.astral.sh/uv/) for more information.

We suggest making a new directory for your project. We'll call it `huggingface-course`.

```bash
mkdir ~/huggingface-course
cd ~/huggingface-course
```

You can then treat this directory as your project root. The command below will create a `pyproject.toml` file and a `.venv` directory.

```bash
uv init
```

We recommend using virtual environments to avoid package conflicts. Think of them as isolated Python setups for different projects.

```bash
uv venv
```

From now on, `uv` will use this virtual environment for all your commands **in this project**. Then activate the virtual environment:

```bash
source .venv/bin/activate
```
When activated, your terminal prompt will change to show `(.venv)`. To deactivate later, just run `deactivate`.

Now we can add the libraries to our project using `uv add` which will add the libraries to the `pyproject.toml` file and install them in the virtual environment.

```bash
uv add install transformers datasets gradio "huggingface_hub[mcp]"
```

Just to be sure, let's test the installation:

```bash
python -c "import huggingface_hub, transformers, datasets, gradio; print('✅ Ready to go!')"
```

> [!TIP]
> Always activate your virtual environment before installing packages or running Python scripts for this course!

## Get Your Access Token

To upload models, create private repos, and access gated models, you'll need to authenticate:

```sh
hf auth login
```

This will ask for your Hugging Face token. Get yours from [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
