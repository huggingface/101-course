## Building with open source models

Beyond trying models, you can build your own tools and applications using several approaches, each with different levels of complexity and control.

**Widgets** allow you to try models directly in their model cards. This gives you a quick overview of what the model can do without any setup or account requirements.

**The Playground** lets you try models directly on the website with advanced controls and parameter tuning. No coding is required, but you get more customization options.

**API Calls** enable you to integrate models via simple HTTP requests into your own applications and services.

**Python Libraries** let you download and run models locally for full control over the execution environment.

<Tip>

Start simple! Most people begin with browser widgets to understand what models can do, then move to APIs or Python as their projects grow more complex.

</Tip>

## Widgets - Quick Model Testing

Every model on the Hub has an interactive widget that lets you test it instantly. No account needed, no setup - just type and see what happens!

To use widgets effectively, visit any model page such as [`openai/gpt-oss-120b`](https://huggingface.co/openai/gpt-oss-120b). Look for the widget on the right side of the screen, which provides an immediate way to interact with the model. Start by trying the example inputs first to understand the expected format, then experiment with your own inputs to see how the model responds.

Different types of models offer different interaction possibilities. Text models let you type prompts for stories, questions, or creative writing, as demonstrated by models like [`openai/gpt-oss-120b`](https://huggingface.co/openai/gpt-oss-120b). Image models allow you to describe what you want to see and generate custom images. Text-to-speech models convert your written text into audio output, such as the [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) model.

<Tip>

Widget not working? Some models are popular and may be busy. Try again in a few minutes, or look for similar models that aren't as crowded.

</Tip>

## The Playground - Advanced Experimentation

The Playground offers more sophisticated controls and settings that help you understand and compare models in depth.

What makes Playgrounds particularly valuable is their advanced parameter controls. You can adjust temperature to control randomness, modify length limits, and experiment with other settings that affect model behavior. The ability to compare multiple models side by side helps you understand which approach works best for your specific use case. You can save and share successful experiments, building a library of configurations that work well for different tasks. Provider selection allows you to route requests through different inference providers based on your needs for speed, cost, or specific capabilities.

<Tip>

Pro Tips:
- Start with default settings, then experiment with one parameter at a time
- Save combinations that work well for future use
- Try the same prompt with different models to see how they compare

</Tip>

## API Calls - Build Real Applications

Ready to integrate AI into your application? APIs let you add AI capabilities with just a few lines of code.

The process is straightforward: send a request to the model with your input, receive the AI's response from the API, and use that response in your application. This simple pattern enables powerful integrations without the complexity of managing models yourself.

**Simple API Example (Python):**

```python
from huggingface_hub import InferenceClient

client = InferenceClient()
response = client.text_generation(
    "Write a short story about a robot:",
    model="microsoft/DialoGPT-large"
)
print(response)
```

APIs provide significant advantages for application development. There's no setup required since models run on Hugging Face servers, not yours. The infrastructure automatically handles traffic spikes through auto-scaling. You can choose from multiple providers like Hugging Face, Together AI, and others based on your specific needs. Limited free usage is available for experimentation, letting you test before committing to paid plans.

## Local Apps

Running models on your computer provides complete control and privacy for your AI applications.

Local execution offers several compelling advantages. Your data never leaves your machine, ensuring complete privacy and security. The speed depends entirely on your hardware rather than server availability or network conditions. You have complete control over model configuration and can customize exactly how you want them to behave. There are no API fees, giving you unlimited usage once you've downloaded the model.

## How to Get Started

Getting started with local apps involves a few straightforward steps.

First, enable Local Apps in your account settings if this feature is available to you.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/settings.png)

Next, choose a supported model from the Hub by searching for models compatible with your preferred local app.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/search_llamacpp.png)

Then select the local app from the "Use this model" dropdown on the model page.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/button.png)

Finally, copy and run the provided command in your terminal.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/command.png)

<Tip>
New to local apps? Start with LM Studio or Jan - they have user-friendly interfaces that make getting started easy!
</Tip>

## Popular Local Apps

### Llama.cpp

Llama.cpp is a high-performance C/C++ library optimized for CPU inference. Based on the [GGUF format](https://huggingface.co/docs/hub/en/gguf) for efficient model loading, it's ideal for CPU-based inference when you need maximum performance.

```sh
# Install with brew (Mac/Linux)
brew install llama.cpp

# Run a model directly from the Hub
llama-cli -hf bartowski/Llama-3.2-3B-Instruct-GGUF:Q8_0
```

### LM Studio

LM Studio is a desktop application with an intuitive graphical interface for downloading and running local LLMs. It's perfect for beginners who want a GUI rather than command-line tools. Features include a built-in model browser and downloader, a chat interface similar to ChatGPT, and developer APIs for integration with other applications.

### Jan

Jan is an open-source chat application that can run completely offline with document chat capabilities. It's designed for privacy-focused users who want complete offline operation. You can upload and chat with your files, and it provides an OpenAI-compatible API server for integration with other tools.

<Tip>
Model formats matter. Look for GGUF format models — they're optimized for local inference and work with most local apps. You can [browse GGUF models](https://huggingface.co/models?library=gguf).
</Tip>

## Finding the Right Model

With many models available on the Hub, finding the right one for your needs requires some strategy.

Browse by task using the task categories like text generation, image creation, or translation. Each category displays the most popular and recently updated models, helping you compare different approaches and performance levels.

Check the statistics to understand community adoption and quality. Downloads indicate real-world usage and community acceptance. Likes provide feedback about model quality from users. Recent updates suggest active development and ongoing maintenance.

Filter by your specific needs to narrow down options. Consider model size - smaller models work better for mobile or real-time applications, while larger models handle more complex tasks. Look for models trained on your target languages if you need multilingual support. Make sure the license fits your use case, whether that's commercial application, research, or personal use.
