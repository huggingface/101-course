# The Hugging Face Hub

Welcome to the Hugging Face Hub! 🤗

The Hugging Face Hub is a collaborative platform for artificial intelligence development and deployment. It serves as a centralized repository where developers, researchers, and organizations share machine learning models, datasets, and applications.

The platform functions as a version-controlled repository system for AI resources, similar to how GitHub works for code. It enables collaboration and sharing across the machine learning community.

<Tip>

It's not just about software and data! The hub is also full of demos, blog posts, papers, and posts that anyone can read and understand on their journey.

</Tip>

## What Makes the Hugging Face Hub Special?

The Hub hosts over 500,000 machine learning models, more than 100,000 datasets, and over 300,000 interactive demonstrations called Spaces. These resources are contributed by developers and researchers worldwide.

The platform emphasizes openness and documentation. Models, datasets, and applications include documentation that helps users understand how to use and build upon existing work. This collaborative approach allows developers to build on previous innovations.

The platform uses Git-based version control, applying software development practices to machine learning. Changes to models are tracked, contributions are documented, and improvements can be shared with the community.

What makes this community special? It's simple: everyone shares their work openly. Students collaborate with researchers, startups use the same tools as big tech companies, and knowledge flows freely across all experience levels. Let's get you connected!

</Tip>

## The Three Pillars of AI Collaboration

The Hub's architecture is built around three fundamental pillars that work together to create a complete AI ecosystem. Understanding these pillars is crucial for anyone looking to participate in this collaborative environment.

**Models** form the first pillar, the hub contains the largest collection of pre-trained AI models. These models cover major AI tasks including natural language processing for text understanding and generation, computer vision for image analysis, and audio processing for speech and music tasks. Available models include text generation, image creation, translation systems for many languages, and code generation tools. For example, OpenAI [gpt-oss](https://huggingface.co/openai/gpt-oss-120b) is available on the hub.

**Datasets** comprise the second pillar, providing training and evaluation data for machine learning development. As well as datasets for analysis, observation, and archive; for example, [NASA shares some amazing datasets](https://huggingface.co/nasa-impact).

These datasets include text collections for language models, image repositories for computer vision, audio datasets for speech processing, and multilingual collections. The quality and variety of these datasets affect the capabilities of models trained on them.

**Spaces** represent the third pillar, providing interactive applications that demonstrate AI models. These Spaces allow users to try models without technical setup, share applications, learn from community examples, and showcase AI projects. They serve as a bridge between AI technology and user-friendly applications. For example, you can edit images with AI models in [Qwen Edit](https://huggingface.co/spaces/Qwen/Qwen-Image-Edit).

## Advanced Integration Capabilities

The Hub's integration capabilities extend beyond basic hosting. The platform supports the Model Context Protocol (MCP), which enables AI models to connect to the Hub and spaces on it. This integration allows for real-time information access and specialized usage of spaces. For example, AI tools like ChatGPT can use the Hub to access models or use spaces as tools.

The Hub offers AI inference via specialized providers, allowing developers to choose options for their specific needs. This includes free tiers for experimentation, enterprise scaling for production applications, and specialized hardware acceleration for demanding workloads.

## Why the Hub Matters for Everyone

The Hugging Face Hub serves different user communities. For beginners learning AI, the Hub offers opportunities to learn by trying models directly in the browser without complex installations or expensive hardware. Documentation and community support help newcomers understand how to use the platform.

Professional developers can use the Hub's integration capabilities to incorporate models into applications with relatively simple code. The API infrastructure allows prototypes to scale to production. The platform supports multiple programming languages and frameworks.

For researchers and academics, the Hub provides a platform for collaboration and knowledge sharing. Models and datasets can be published with reproducibility features, allowing others to build upon previous work. Papers can be shared with the community, and the platform can reference assets like models and datasets from the paper. The platform's reach helps research have broader impact in the field.

## The Power of Open Source Innovation

The Hub follows open source principles, promoting transparency in AI development. Unlike closed systems, the Hub allows users to examine how models work, understand their training processes, and identify potential limitations or biases. This transparency helps build trust in AI systems and supports responsible use. The open source model of the Hubmakes AI development more accessible. Small teams and individual researchers can access the same tools and models used by large corporations, which helps level the playing field for innovation.

## Getting Started on Your AI Journey

Getting started with the Hugging Face Hub is straightforward:

1. [Visit the Hugging Face Hub](https://huggingface.co)
2. Try out models in the browser
3. [Create a free account](https://huggingface.co/join)
4. Participate in the community

Many models include interactive widgets that allow you to test them immediately. These widgets provide a hands-on way to understand what different models can do, including generating text, creating images from descriptions, and translating between languages. This immediate feedback helps build understanding of AI capabilities and limitations.

Creating a free account provides additional features, including the ability to save favorite models, participate in community discussions, and share your own creations. The account setup process is simple and provides access to the collaborative features.
