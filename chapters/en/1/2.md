# Programming with AI Models

Ready to integrate AI into your applications? The `InferenceClient` from the `huggingface_hub` library lets you add AI capabilities with just a few lines of code.

The process is straightforward: send a request to the model with your input, receive the AI's response, and use that response in your application. This simple pattern enables powerful integrations without managing models yourself.

> [!TIP]
> Since you've already set up your Python environment in Unit 0, we'll jump straight into the code examples. If you need to set up your environment, go back to Unit 0 and follow the steps to set up your environment.

## Your First AI Integration

Let's start with a simple text generation example:

```python
from huggingface_hub import InferenceClient

# Initialize the client
client = InferenceClient()

# Generate text using GLM-4.6
response = client.text_generation(
    prompt="Write a haiku about programming:",
    model="zai-org/GLM-4.6",
    max_new_tokens=50
)

print(response)
```

This should output something like:

```
# A haiku about programming:

I love to code
Every day I code
My code is great
```

That's it! You've just integrated a state-of-the-art language model into your application.

## Working with Different Modalities

The same client can work with various AI tasks from text generation to image generation to question answering. Lets' try a few of other tasks.

Below, we can define a function to create an image from a description.

> [!TIP]
> For this snippet, we will need the PIL library. Install it with `uv pip install pillow`.

```python
def create_image(description):
    client = InferenceClient(
        provider="fal-ai",
    )

    image = client.text_to_image(
        prompt=description,
        model="black-forest-labs/FLUX.1-dev",
    )
    return image


# Generate an image
create_image("A peaceful mountain lake at sunrise")
```

This function will use the `fal-ai` provider to create an image with the `black-forest-labs/FLUX.1-dev` model and return a `PIL.Image` object. The result should look like this:

![A peaceful mountain lake at sunrise](https://huggingface.co/datasets/huggingface-101/images/resolve/main/chapter1/2_0.png)

Let's try audio generation with the `hexgrad/Kokoro-82M` model.
