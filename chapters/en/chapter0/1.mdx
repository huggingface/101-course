# Introduction[[introduction]]

Welcome to Hugging Face 101! This course will teach you everything you need to know about the Hugging Face ecosystem - home to over 1.7 million models, 400k datasets, and 600k interactive demos.

You'll learn three ways to work with Hugging Face: through the web interface (no coding required), via APIs (for quick integration), or with Python libraries (for full control). Pick the approach that fits your project, or mix and match as needed!

## What You'll Learn

By the end of this course, you'll know how to:

- **Navigate the Hub**: Find and use the models, datasets, and demos you need
- **Use AI APIs**: Integrate text generation, image creation, and more into your projects  
- **Share Your Work**: Upload models, datasets, and demos for others to use
- **Build Interactive Demos**: Create Spaces that showcase your AI projects
- **Evaluate Models**: Test AI models to see if they work for your use case
- **Use Advanced Features**: Explore newer capabilities like the Model Context Protocol (MCP)

<Tip>
**Not sure what some of these terms mean?** Don't worry! We'll explain everything as we go. This course assumes no prior AI experience.
</Tip>

## Why Learn Hugging Face?

Recent innovations like the [Model Context Protocol (MCP)](https://huggingface.co/blog/building-hf-mcp) are making AI models even more powerful by connecting them to external tools and data.

Whether you're new to AI, a developer adding AI features to your app, or a researcher sharing your work, Hugging Face gives you the tools and community to succeed.

<Tip>
**Why start here?** Most AI breakthroughs get shared on Hugging Face first. Learning this platform means you'll always have access to the latest and greatest in AI.

### What Each Library Does

- **`huggingface_hub`**: Your connection to the Hub - handles authentication, downloads, uploads, and includes MCP support
- **`transformers`**: Thousands of pre-trained models for text, images, audio, and more
- **`datasets`**: Easy access to datasets and tools for processing your own data  
- **`gradio`**: Build interactive web demos with just a few lines of code

The optional `huggingface_hub[inference]` package adds support for the new [Model Context Protocol (MCP)](https://huggingface.co/docs/huggingface_hub/en/package_reference/mcp), which lets AI models connect to external tools and data sources.

You're now ready for all the projects in this course!

## Local Python Setup (Advanced)

*For experienced developers who want to work locally instead of Colab.*

If you prefer local development, first install Python from [python.org](https://python.org) or follow [this detailed guide](https://realpython.com/installing-python/).

Verify Python is installed:
```bash
python --version
```

We recommend using virtual environments to avoid package conflicts. Think of them as isolated Python setups for different projects.

Create a project directory and virtual environment:

```bash
# Create and enter your project directory
mkdir ~/huggingface-course
cd ~/huggingface-course

# Create virtual environment
python -m venv .env

# Activate it (Mac/Linux)
source .env/bin/activate

# On Windows, use:
# .env\Scripts\activate
```

When activated, your terminal prompt will change to show `(.env)`. To deactivate later, just run `deactivate`.

<Tip>
**Pro tip**: Always activate your virtual environment before installing packages or running Python scripts for this course!
</Tip>

### Install the Libraries

Now install the same Hugging Face libraries:

```bash
pip install huggingface_hub transformers datasets gradio
pip install "huggingface_hub[inference]"  # Optional MCP support
```

Test the installation:

```bash
python -c "import huggingface_hub, transformers, datasets, gradio; print('✅ Ready to go!')"
```

## Get Your Access Token

To upload models, create private repos, and access gated models, you'll need to authenticate:

```python
from huggingface_hub import login
login()
```

This will ask for your Hugging Face token. Get yours from [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).

<Tip>
**Don't have a token yet?** You can still follow most of the course without one. Create a token when you're ready to start uploading your own models and datasets.
</Tip>
