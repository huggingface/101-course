# Using Open Source Models

Ready to try some AI models? The Hugging Face Hub hosts loads of open-source models you can use right in your browser.

You get access to the same models that power many AI applications. Whether you're a curious beginner or an experienced developer, you can experiment with text generation, image creation, translation, and more.

Moreover, you can scale up these same models to build your own custom AI applications.

> [!TIP]
> New to AI models? This unit is for you! We're going to explain everything as we go and provide plenty of examples that work without any coding.

## Zero Setup Required

The easiest way to try models is using their interactive widgets in their model cards on the Hub. No account needed, no setup - just type and see what happens!

### What's a Model Card?

Before we start, what is a model card? We'll explore this in more detail in the next sections, but for now, think of a model card as a models README or product packaging. 

It contains all the core information about the model, such as its capabilities, limitations, and how to use it. It also contains useful tools to try the model out quickly, or bootstrap your own application. 

For example, from a model card you can access a widget to try the model via a chat interface, or you can copy a code snippet to drop it into your own application.

Different types of models offer different interaction possibilities. Text models let you type prompts into a chat interface, as demonstrated by models like [`openai/gpt-oss-120b`](https://huggingface.co/openai/gpt-oss-120b). Image models allow you to upload an image and ask the model to modify it. Text-to-speech models convert your written text into audio output, such as the [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) model.

### Try Qwen Image Edit via a Space

Chatting and generating text is fun, but let's try something more visual. Spaces are interactive demos you can try in your browser without any installation or setup.

We're going to experiment with a Space that lets you edit images based on text instructions from Qwen.

Qwen Image Edit is a **image and text to image** model. It can take a text prompt and generate an image based on it. Usually, the text prompt is used to describe the changes you want to make to the image. For example, you can ask the model to "make the sky more dramatic".

## Compare models in the Playground

Let's work on a practical use case. For example, we want use a new model in our application and we need to compare models to see which one is best for our use case. This can be done in the Playground.

The Playground offers more detailed controls and lets you compare different models side by side.

### Try DeepSeek R1 in the Playground

DeepSeek R1 is a reasoning model that excels at complex problem-solving. Access it through the [Hugging Face Playground](https://huggingface.co/playground):

<!-- TODO: @burtenshaw add an image of the Playground -->

Navigate to [huggingface.co/playground](https://huggingface.co/playground) and select "DeepSeek R1" from the model dropdown. Test its reasoning abilities with puzzles like "A farmer has 27 sheep. All but 9 have a 1 in 5 chance of dying. How many sheep are left?".

> [!TIP]  
> Start with default settings, then experiment with one parameter at a time. Adjust temperature to control randomness (lower values give more focused responses, higher values more creative ones). Use the comparison feature to see how different models handle the same prompt.

The Playground offers settings that help you understand and compare models and their parameters. You can adjust temperature to control randomness, modify length limits, and experiment with other settings that affect model behavior.
