## Building with open source models

Beyond just trying models, you can build your own projects, tools, and applications with them.

**🌤️ Widgets** - Try models directly in their model cards. This will give a quick overview of what the model can do.

**🖥️ The Playground** - Try models directly on the website. No coding required! Perfect for exploring what's possible and testing out new ideas.

**🔌 API Calls** - Integrate models into your applications with simple HTTP requests. Great for building apps without managing infrastructure.

**🐍 Python Libraries** - Download and run models locally with full control. Best for custom applications and advanced use cases.

<Tip>

**Start simple!** Most people begin with browser widgets to understand what models can do, then move to APIs or Python as their projects grow more complex.

</Tip>

## 🌤️ Widgets - Quick Model Testing

Every model on the Hub has an interactive widget that lets you test it instantly. No account needed, no setup - just type and see what happens!

**How to Use Widgets:**
1. Visit any model page. For example, [gpt-oss-120b](https://huggingface.co/openai/gpt-oss-120b)
2. Look for the widget on the right side of the screen
3. Try the example inputs first, then experiment with your own

**What You Can Try:**
- **Text models**: Type prompts for stories, questions, or creative writing. For example, [gpt-oss-120b](https://huggingface.co/openai/gpt-oss-120b)
- **Image models**: Describe what you want to see and get custom images. For example, [Qwen Image Edit](https://huggingface.co/spaces/Qwen/Qwen-Image-Edit)
- **Text to speech models**: Type in text and get audio. For example, [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M)

<Tip>

**Widget not working?** Some models are popular and may be busy. Try again in a few minutes, or look for similar models that aren't as crowded.

</Tip>

## 🖥️ The Playground - Advanced Experimentation

The Playground takes widgets to the next level with more controls and settings. Perfect for understanding how AI models work and compare them.

**What Makes Playgrounds Special:**
- **Parameter controls**: Adjust temperature, length, and other settings
- **Multiple models**: Compare different models side by side
- **Save and share experiments**: Keep track of what works best
- **Multiple providers**: Compare different providers and models

<Tip>

**Pro Tips:**
- Start with default settings, then experiment with one parameter at a time
- Save combinations that work well for future use
- Try the same prompt with different models to see how they compare

</Tip>

## 🔌 API Calls - Build Real Applications

Ready to integrate AI into your own applications? APIs let you add AI capabilities with just a few lines of code - no infrastructure management needed!

**How APIs Work:**
1. Send a request to the model with your input
2. Get back the AI's response from the API
3. Use that response in your application

**Simple API Example (Python):**

```python
from huggingface_hub import InferenceClient

client = InferenceClient()
response = client.text_generation(
    "Write a short story about a robot:",
    model="microsoft/DialoGPT-large"
)
print(response)
```

**API Benefits:**
- **No setup**: Models run on Hugging Face servers, not yours
- **Auto-scaling**: Handles traffic spikes automatically  
- **Multiple providers**: Choose from Hugging Face, Together AI, and more
- **Free tier**: Generous limits for experimentation

## 🖥️ Local Apps 

Want to run AI models directly on your computer? Local apps let you use Hugging Face models without sending data to remote servers. Perfect for privacy, speed, and cost savings!

**Why Use Local Apps:**
- **Privacy**: Your data never leaves your machine
- **Speed**: Your hardware is the limiting factor, not server speed
- **Control**: Configure models exactly how you want them
- **Cost**: No API fees for unlimited usage

## How to Get Started

Local apps are applications that can run Hugging Face models directly on your machine. To get started:

1. **Enable local apps** in your [Local Apps settings](https://huggingface.co/settings/local-apps).

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/settings.png)

1. **Choose a supported model** from the Hub by searching for it.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/search_llamacpp.png)

3. **Select the local app** from the "Use this model" dropdown on the model page.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/button.png)

4. **Copy and run** the provided command in your terminal.

![Local Apps](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/local-apps/command.png)

<Tip>
**New to local apps?** Start with LM Studio or Jan - they have user-friendly interfaces that make getting started easy!
</Tip>

## Popular Local Apps

### Llama.cpp

High-performance C/C++ library optimized for CPU inference. Based on the [GGUF format](https://huggingface.co/docs/hub/en/gguf) for efficient model loading.

**Best for:** CPU-based inference, maximum performance
```sh
# Install with brew (Mac/Linux)
brew install llama.cpp

# Run a model directly from the Hub
llama-cli -hf bartowski/Llama-3.2-3B-Instruct-GGUF:Q8_0
```

### LM Studio

Desktop application with an intuitive graphical interface for downloading and running local LLMs.

**Best for:** Beginners who want a GUI experience
- Built-in model browser and downloader
- Chat interface similar to ChatGPT
- Developer APIs for integration

### Jan
Open-source ChatGPT alternative that runs entirely offline with document chat capabilities.

**Best for:** Privacy-focused users who want to chat with documents
- Complete offline operation
- Upload and chat with your files
- OpenAI-compatible API server



<Tip>
**Model formats matter!** Look for GGUF format models on the Hub - they're optimized for local inference and work with most local apps. You can [browse GGUF models here](https://huggingface.co/models?library=gguf).
</Tip>

## Finding the Right Model

With over 500,000 models on the Hub, how do you find the right one? Here are some tips:

**Browse by Task:**
- Use the task categories (text generation, image creation, translation, etc.)
- Each category shows the most popular and recent models
- Compare different approaches and performance levels

**Check the Stats:**
- **Downloads**: Shows community adoption and real-world usage
- **Likes**: Community feedback and quality indicators
- **Recent updates**: Active development and maintenance

**Filter by Your Needs:**
- **Model size**: Smaller for mobile/real-time, larger for complex tasks
- **Language**: Find models trained on your target languages
- **License**: Make sure it fits your use case (commercial, research, etc.)
